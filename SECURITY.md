# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any public repository under [`ridloabelian`](https://github.com/ridloabelian) or [SAIF](https://saif.co.id), please do **not** open a public GitHub issue.

Instead, report it privately via one of these channels:

1. **GitHub Private Vulnerability Reporting** — Open the affected repository's **Security -> Advisories -> Report a vulnerability** page.
2. **Direct Contact** — Reach out through the contact channels listed at [ridlo.id](https://ridlo.id) or [saif.co.id](https://saif.co.id).

Please include reproduction steps, affected component/commit, and potential impact. We aim to acknowledge reports within 48 hours.
